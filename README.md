# One-Liner Laughs

One original funny line, at most 200 characters, a single joke that lands on a cold read.

Entry: `My agent summarized a 40-page report into one line: We are doomed, but the slides look great.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
